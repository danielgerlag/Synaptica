##  CRITICAL - FIX FIRST (TODAY)

### 1. PATH TRAVERSAL (main.rs:167-172)
- **Attack**: GET /../../../etc/passwd serves system files
- **Fix**: Canonicalize path and verify within base directory
- **Time**: 30 minutes
- **Impact**: CRITICAL security hole

### 2. METRICS PANIC (metrics.rs:12,20,22,25,32-44)
- **Problem**: .unwrap() on Prometheus registration  app crash
- **Fix**: Return Result<> and handle errors gracefully  
- **Time**: 45 minutes
- **Impact**: Can't start server

### 3. WAL SILENT FAILURES (distributed_tx.rs:137-154)
- **Problem**: Disk write errors ignored, recovery impossible
- **Fix**: Return Result from persist_entry(), propagate errors
- **Time**: 1 hour
- **Impact**: Data inconsistency after crash

### 4. TRANSACTION STATE LOGIC (distributed_tx.rs:293-301)
- **Problem**: Wrong state after "NO" vote, can still commit
- **Fix**: Transition to Aborting immediately on NO vote
- **Time**: 30 minutes
- **Impact**: Data corruption

### 5. MUTEX POISON (distributed_tx.rs:229,254,269+)
- **Problem**: .lock().unwrap()  panic on poison
- **Fix**: Use error handling OR switch to parking_lot::Mutex
- **Time**: 2 hours (multiple locations)
- **Impact**: Coordinator crash

### 6. TIMING ATTACK (auth.rs:31)

- **Fix**: Use subtle::ConstantTimeComparison
- **Time**: 30 minutes
- **Impact**: Auth bypass

- **Time**: 30 minutes

- **Time**: 30 minutes

- **Time**: 20 minutes
